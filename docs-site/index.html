Jira-style project flow on GitHub

Use GitHub issues, branches, PRs, and milestones as a safer project operating system.

Gira is a Go-built CLI that keeps GitHub as the source of truth while giving humans and agents a concise plan/apply workflow.

Install

curl -fsSL https://raw.githubusercontent.com/StatPan/gira/main/install.sh | sh

Package-manager channels are also available:

npm install -g @statpan/gira
bun install -g @statpan/gira
pipx install gira-cli
python -m pip install --user gira-cli
brew tap StatPan/tap
brew install gira

Daily Loop

gh auth status
gira init --repo OWNER/REPO --path . --dry-run
gira ticket new "TITLE" --goal "GOAL" --acceptance "done criteria" --apply --start
gira ticket pr --apply --draft
gira ticket checks
gira ticket wait --timeout 5m
gira ticket finish --apply

Humans

Preview repository and GitHub changes before applying them, then keep ticket progress visible through GitHub evidence.

Agents

Use Gira commands instead of raw gh when a Gira lifecycle command exists, and keep each PR linked to a source ticket.

Teams

Map Jira concepts onto GitHub without creating a separate planning database or forcing Projects v2 automation into v1.
